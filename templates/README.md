# Templates

- `PROJECT_SPEC.md` — executable project scope and interfaces.
- `TODO.md`, `CURRENT.md`, `BLOCKED.md`, `DONE.md` — durable work state.
- `ACCEPTANCE_CHECKLIST.md` — completion gate.
- `REPAIR_RECORD.md` — reproducible diagnosis and bounded repair record.
- `state.example.json` — machine-readable state matching the published schema.

Copy templates into a project, rename where needed, and resolve every bracketed field. Do not leave placeholder text in a release.
